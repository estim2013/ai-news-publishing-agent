# AI News Publishing Agent

AI-сервис для пакетной подготовки новостных публикаций из внешних источников.

## Задача

Сократить ручную работу редактора при обработке потока новостей: загрузить исходные ссылки, извлечь факты, подготовить самостоятельный текст и проверить его перед публикацией.

## Что реализовано

- загрузка статьи по URL и очистка текста от навигации, рекламы и служебных блоков;
- извлечение заголовка, основного текста и изображения;
- подготовка структурированного набора фактов для LLM;
- глубокий рерайт с заголовком, лидом и основным текстом;
- проверка языка, структуры ответа, отказов модели и чрезмерного совпадения с источником;
- повторная генерация при невалидном результате;
- пакетная обработка до 10 материалов с отслеживанием статуса каждого задания;
- поддержка нескольких LLM-провайдеров с резервным маршрутом;
- режим `dry-run` для проверки результата без публикации;
- браузерная автоматизация заполнения редакционной формы;
- простой веб-интерфейс и API для запуска заданий.

## Архитектура

```mermaid

    A[URL или исходный текст] --> B[Извлечение и очистка]

    D --> E[Проверки качества]
```

## Стек

`Node.js`, `Express`, `OpenAI API`, `DeepSeek API`, `GigaChat API`, `Playwright`, `Cheerio`, `HTML/CSS/JavaScript`.

## Контроль качества

- модель получает очищенный текст и отдельный набор фактов;
- результат возвращается в структурированном JSON;
- неполные, невалидные и непригодные ответы отклоняются;
- текст проверяется на сходство с источником;
- публикация отделена от генерации и может быть отключена;
- ошибки сохраняются отдельно для каждого материала в пакете.

## Статус

Рабочий MVP. Название целевой площадки, селекторы формы, учётные данные и детали производственного окружения исключены из публичного описания.
